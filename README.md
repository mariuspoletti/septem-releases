# Septem for Mac

Septem is a focus timer and IB study planner for Mac.

**[Download the latest version](../../releases/latest/download/Septem.zip)** · [All versions and what changed](../../releases)

This repository holds only the released app, one release per version, with its notes. The source code isn't here.

## Updates

Septem checks this page once a day. When there's a new version, it shows a small banner with what's new and an Install button. Nothing is downloaded until you click it. Your data stays on your Mac and is kept.

## Opening Septem the first time

macOS may say Septem is from an unidentified developer. Right-click Septem.app, choose Open, then Open again. The note "How to open Septem.txt" in the download explains it step by step.
